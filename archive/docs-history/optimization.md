## 安全风险摘要

::: danger 命令注入
exec MCP Tool 暴露命令执行，AI 被 prompt injection 可能执行恶意命令。缓解：allowlist + approval + 沙箱。
:::

::: danger 未授权远程桌面
屏幕推流 + 键鼠直通 = 完全控制。缓解：Gateway auth token + Tailscale 加密 + 被控端确认。
:::

::: danger Prompt Injection
不受信内容携带恶意指令操纵 AI。缓解：旗舰模型 + reader agent 预处理 + approval。
:::

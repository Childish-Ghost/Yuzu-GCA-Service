# R-004 屏幕推流技术选型

> 2026-07-26 · **结论修正**：AI 驱动场景**不需要推流**，R-001 按需截屏即可
> 推流仅用于 Phase 4 人看的桌面客户端（Tauri），届时再选型

## 关键洞察（用户指出）

AI 不是人——人看屏幕需要 30fps 连续流，但 AI 是**逐帧分析**的：
- 每张图发给 MiniMax-M3 需要 1-3 秒处理
- 10fps 推过去 = 10 张图堆积，AI 分析不过来 = 10-30 秒延迟
- **比现在的"按需截屏"还慢**

**AI 驱动操控的正确模式**：

```
AI 操作（R-002 点击/打字）
  → AI 调 R-001 截一张图
  → 分析结果对不对
  → 决定下一步
  → 再操作 → 再截一张
```

这就是 R-001 + R-002 的按需循环——**现有的工具链已经是对的架构**，不需要推流。

## 推流什么时候需要

推流是给**人**看的，不是给 AI 用的：
- Phase 4 Tauri 桌面客户端——人在屏幕前实时看远程桌面
- 届时再选型（WebSocket JPEG / WebRTC / VNC）
- 当前不需要实现
